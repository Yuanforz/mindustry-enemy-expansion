# 参考资料

这个目录里的东西只用于查阅，不会打包进模组。

- `schematics/`：从网上收集的 2463 个纯艾利克尔蓝图（`mixed/` 里另有 414 个混合科技的），以及清单 `MANIFEST.tsv`（名称、尺寸、用到的方块、来源网址、作者、许可、类别）。这些是别人的作品，许可各不相同，见清单；只作为设计参考读取，没有执行过其中任何内容。用 `tools/run.sh schematic 文件` 可以把蓝图画成文字。
- `meta-report.md`：艾利克尔的配方、比例、打法、炮塔定位，以及已有基地 AI 方案的调研，逐条带出处。
- `mechanics-spec.md`：从 v160.7 源码整理的方块行为（管道、钻机、电力、液体、热量、兵工厂、建造规则），逐条带源码行号。
- `content.txt`：直接从游戏里导出的艾利克尔科技树全部方块和单位的数据（造价、消耗、产出）。游戏更新后用 `tools/run.sh content` 重新生成。
